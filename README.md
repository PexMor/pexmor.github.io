# pexmor.github.io

The modules or software I made:

* [NetModule](https://pexmor.github.io/NetModule) - STM8 + ENC28J60 aka HW-584v2 (STM8S-105-S6)
* [QR i/o](https://pexmor.github.io/qr-io) - read, show and share (websocket)
* [Projector](https://pexmor.github.io/projector) - An experimental projector project
* [Json2](https://pexmor.github.io/json2) - Naive and simple tool inspired by `xml2`

## Reference repos

* [X.509: CA and Certs](https://github.com/PexMor/ca-n-certs)
  - ✅ Root CA and Intermediate CA setup
  - ✅ Host/Server certificate generation (TLS/SSL)
  - ✅ S/MIME email certificates with PKCS#12 export
  - ✅ Certificate Revocation Lists (CRL)
  - ✅ OCSP Responder (RFC 6960 compliant)
  - ✅ Document signing with timestamps (TSA)
  - ✅ PDF Signing (with visible stamp and actuall TSA Signature)
* [TLS Cert](https://github.com/PexMor/urlmonitor) - check the validity of X.509 certs on web
* [QR payments](https://pexmor.github.io/spayd-applied/) - Czech QR/SPAYD [Git Repo](https://github.com/PexMor/spayd-applied)

* [Data Proxy](https://github.com/PexMor/pxbox) - A message broker API for universal M2M/M2H/H2M messaging
